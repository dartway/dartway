# dartway_starter — project conventions

This file is yours. The installer preserves it and updates only its marked connection block.
Read `.agents/DARTWAY.md` for the framework laws and skill index. `CLAUDE.md` imports this file.

## Project conventions

Put project rules and overrides of framework defaults here, with the reason for each decision.
Framework laws cannot be overridden. Managed files under `.agents/` are overwritten on update;
custom skills belong in `.agents/skills/` under a name without the `dartway-` prefix.
