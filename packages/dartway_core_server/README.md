# dartway_core_server

The [DartWay](https://dartway.dev) application server, on `dart:io`: HTTP calls per DTO, the live
update socket, handlers and access, the call context, accounts/identities/keys, idempotent
commands, channels, jobs, uploads to two buckets, routes for external doors, alerts.

It re-exports `dartway_core_shared` (the wire contract) and `dartway_orm` (typed Postgres access),
so a project's server package needs only this one framework dependency. `testing.dart` holds
`DwTestServer` and the fixtures a project's own suites are written against.

## Where it sits

`dartway_core_server` is one of the six packages of the core family, versioned in lockstep. It is
what a project's server package (generated by `dartway create`, from `template/`) depends on
directly — you are not expected to add it to a project that did not start from the template or the
CLI's scaffolding.

## Documentation

The full documentation lives in the framework's repository, at

[`docs/4-server/`](https://github.com/dartway/dartway/tree/master/docs/4-server) for the server
