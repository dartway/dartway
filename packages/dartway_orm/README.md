# dartway_orm

Typed PostgreSQL access, schema and migrations for [DartWay](https://dartway.dev) servers: row
classes, typed queries, transactions, locks, schema, and migrations (`DwMigrationCli`).

## Where it sits

`dartway_orm` is one of the six packages of the core family, versioned in lockstep, and it is
internal to the family: `dartway_core_server` re-exports it, so a project's server package reaches
it through `dartway_core_server` rather than depending on it directly. A row class change is a
migration, generated by `dartway_generator` and run through `DwMigrationCli`.

`dartway create` wires this up already — this package is not something you add by hand to a
project.

## Documentation

The full documentation lives in the framework's repository, at
[`docs/`](https://github.com/dartway/dartway/tree/master/docs) — start at
[`docs/4-server/`](https://github.com/dartway/dartway/tree/master/docs/4-server) for the database
and migrations this package provides.
