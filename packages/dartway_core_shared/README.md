# dartway_core_shared

The shared contract of the [DartWay](https://dartway.dev) core family: what travels between a
server and its clients, and how. Pure Dart, on every side — it compiles into the server, the
Flutter app, and nowhere reaches for Flutter, a database or IO.

It carries the DTO kinds (`DwDataObject`, the request kinds, `DwActionCommand`), results and
refusals, live channels, and the wire protocol itself (`DwHttpContract`, `DwApiResponse`,
`DwUpdateTransport`, live messages, `dwProtocolVersion`), plus the framework's own auth and file
DTOs.

## Where it sits

`dartway_core_shared` is one of the six packages of the core family, versioned in lockstep. Most
projects never depend on it directly: `dartway_core_server` and `dartway_core_flutter` each
re-export it, and a project's own shared package (generated by `dartway_generator`) depends on it
to declare the project's own DTOs.

`dartway create` generates a project with this dependency already wired into its shared package —
this package is not something you add by hand.
